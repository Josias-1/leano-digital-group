# Leano writing templates

All templates embed the approved Leano lockup and contain replaceable placeholders in square brackets.

## Corporate stationery layouts

The `enterprise/` folder contains the new conservative-corporate layouts. These are print-ready HTML documents that can be opened in a browser or Word, edited, and printed to PDF:

- `enterprise/Leano-Letterhead.html`
- `enterprise/Leano-Proposal.html`
- `enterprise/Leano-Invoice.html`

They include the registered company name, address, registration/VAT number, website, sales contact details, and Mr J as the default signatory. Banking details are intentionally marked for confirmation before issue.

| File | Use |
| --- | --- |
| `Leano-Letterhead.docx` | Letterhead for client letters and formal correspondence. |
| `Leano-Proposal.docx` | Proposal structure with executive summary, scope, approach, commercial, and next-step sections. |
| `Leano-Invoice.xlsx` | Invoice worksheet with quantity, rate, subtotal, VAT, and total formulas. |
| `email/Leano-Email-Signature.html` | Personal email-signature template. |
| `email/Leano-Client-Email.html` | Branded client/newsletter email template. |

For the HTML email files, keep `email-signature-logo-760x160.png` in the same `email` folder. Open the HTML file in a browser to preview it, then replace bracketed placeholders before sending through your email platform.
